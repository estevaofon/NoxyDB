# NoxyDB v0.2 Executable Example Design

## Goal

Add one runnable example that teaches the NoxyDB v0.2 document API from a
user's perspective. The example must demonstrate the document model and
persistence without introducing features beyond the v0.2 scope.

## Files

- Add `examples/documents.nx` as the executable walkthrough.
- Add `examples/*.db` to `.gitignore` so users can keep and inspect generated
  databases without accidentally tracking them.
- Add a short README section showing how to run the example.

## Example flow

The example uses `examples/noxydb_v02.db` and is safe to execute repeatedly.
At startup it removes a previous copy of that file so every run has a
deterministic initial state. It then:

1. Opens a database and checks the open state.
2. Stores a user document containing string, int, float, bool, null, an array,
   a nested object, and an array of objects.
3. Stores a second document so multiple keys are visible.
4. Reads the user through `LookupResult` and prints representative fields.
5. Replaces the complete user document and shows that an omitted old field no
   longer exists.
6. Removes the second document and verifies its absence.
7. Closes and reopens the database, proving that the replacement document and
   deletion survived replay.
8. Closes normally while leaving `examples/noxydb_v02.db` on disk for manual
   inspection or another execution.

All writes inspect `PutResult`. Database-open, write, lookup, or replay failure
prints the observable error and stops the relevant flow instead of assuming
success.

## Boundaries

The example uses only the public NoxyDB API. It does not inspect
`DatabaseState`, serialized payloads, or log records, and it does not imply
queries, partial updates, schemas, collections, or other out-of-scope features.

## Validation

- Run `examples/documents.nx` with the Noxy executable produced by the companion
  Noxy JSON branch.
- Run it twice and require both executions to succeed.
- Confirm `examples/noxydb_v02.db` exists afterward and is ignored by Git.
- Run the complete NoxyDB test suite and `git diff --check`.
