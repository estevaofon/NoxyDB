# NoxyDB v0.2 Documents Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox - [ ] syntax for tracking.

**Goal:** Evolve NoxyDB to persist JSON-object documents behind string keys while keeping serialized payloads authoritative and the storage engine JSON-agnostic.

**Architecture:** Add a strict observable JSON encoder to Noxy, then place a focused document.nx codec between the NoxyDB API and the existing raw append-only storage engine. Public values are map[string, any]; in-memory and on-disk values remain serialized strings, and every successful get() decodes a fresh object.

**Tech Stack:** Noxy v0.1.0 language and VM, Go encoding/json, PowerShell test runner, append-only hexadecimal log, Git.

## Global Constraints

- Require a JSON object at the document root.
- Expose string -> map[string, any] publicly.
- Keep DatabaseState.payloads as map[string, string].
- Keep storage.nx unaware of JSON.
- Keep P<TAB><key_hex><TAB><payload_hex>\n and D<TAB><key_hex>\n.
- Preserve append-only writes, strict replay, tombstones, append-before-memory, observable I/O errors, and open/closed/failed states.
- Make each successful get() deserialize a fresh map.
- Add no header, migration, fallback, format discriminator, or v0.1 handling.
- Keep legacy json_dumps unchanged.
- Strict encoding accepts only null, bool, int, finite float, string, arrays, and recursively string-keyed maps.
- Reject bytes, structs, references, callables, channels, wait groups, non-string map keys, non-finite floats, unsupported values, and cycles.
- Do not change the lexer, parser, AST, compiler, bytecode, or type system.
- Do not add any database feature listed as out of scope in the approved specification.

~~~go
package vm

import (
	"errors"
	"math"

	"noxy-vm/internal/value"
)

var (
	errJSONUnsupported = errors.New("value is not JSON-compatible")
	errJSONNonFinite  = errors.New("non-finite float is not valid JSON")
	errJSONCycle      = errors.New("cyclic value is not valid JSON")
)

type strictJSONTraversal struct {
	arrays map[*value.ObjArray]bool
	maps   map[*value.ObjMap]bool
}

func strictJSONValToGo(input value.Value) (interface{}, error) {
	traversal := strictJSONTraversal{
		arrays: make(map[*value.ObjArray]bool),
		maps:   make(map[*value.ObjMap]bool),
	}
	return traversal.convert(input)
}

func (t *strictJSONTraversal) convert(input value.Value) (interface{}, error) {
	switch input.Type {
	case value.VAL_NULL:
		return nil, nil
	case value.VAL_BOOL:
		return input.AsBool, nil
	case value.VAL_INT:
		return input.AsInt, nil
	case value.VAL_FLOAT:
		if math.IsNaN(input.AsFloat) || math.IsInf(input.AsFloat, 0) {
			return nil, errJSONNonFinite
		}
		return input.AsFloat, nil
	case value.VAL_OBJ:
		switch object := input.Obj.(type) {
		case string:
			return object, nil
		case *value.ObjArray:
			return t.convertArray(object)
		case *value.ObjMap:
			return t.convertMap(object)
		default:
			return nil, errJSONUnsupported
		}
	default:
		return nil, errJSONUnsupported
	}
}

func (t *strictJSONTraversal) convertArray(array *value.ObjArray) ([]interface{}, error) {
	if t.arrays[array] {
		return nil, errJSONCycle
	}
	t.arrays[array] = true
	defer delete(t.arrays, array)
	converted := make([]interface{}, len(array.Elements))
	for index, element := range array.Elements {
		item, err := t.convert(element)
		if err != nil {
			return nil, err
		}
		converted[index] = item
	}
	return converted, nil
}

func (t *strictJSONTraversal) convertMap(mapping *value.ObjMap) (map[string]interface{}, error) {
	if t.maps[mapping] {
		return nil, errJSONCycle
	}
	t.maps[mapping] = true
	defer delete(t.maps, mapping)
	converted := make(map[string]interface{}, len(mapping.Data))
	for key, item := range mapping.Data {
		stringKey, ok := key.(string)
		if !ok {
			return nil, errJSONUnsupported
		}
		convertedValue, err := t.convert(item)
		if err != nil {
			return nil, err
		}
		converted[stringKey] = convertedValue
	}
	return converted, nil
}
~~~

~~~~markdown
## Strict observable encoding

The json module exposes strict encoding when callers need explicit failure:

~~~noxy
use json

let value: map[string, any] = {"name": "Noxy", "active": true}
let result: json.EncodeResult = json.dumps_result(value)
if result.success then
    print(result.data)
else
    print(result.error)
end
~~~

json.dumps_result accepts null, bool, int, finite float, string, arrays, and
recursively string-keyed maps. It rejects bytes, structs, references,
callables, channels, wait groups, non-string map keys, NaN, infinities,
unsupported runtime values, and cycles. Reusing an acyclic child in multiple
branches is valid.

On success, data contains complete JSON and error is empty. On failure, data is
empty and error is non-empty. The legacy json_dumps function is unchanged and
retains its permissive compatibility behavior.
~~~~

~~~noxy
use json

struct SerializeResult
    success: bool
    payload: string
    error: string
end

struct DeserializeResult
    success: bool
    value: map[string, any]
    error: string
end

func serialize(value: map[string, any]) -> SerializeResult
    let encoded: json.EncodeResult = json.dumps_result(value)
    if !encoded.success then
        return SerializeResult(false, "", "document is not JSON-compatible")
    end
    return SerializeResult(true, encoded.data, "")
end

func deserialize(payload: string) -> DeserializeResult
    let value: map[string, any] = {}
    let success: bool = json_loads(payload, value)
    if !success then
        return DeserializeResult(false, value, "invalid document payload")
    end
    return DeserializeResult(true, value, "")
end
~~~

~~~noxy
use io
use strings

struct ReplayResult
    success: bool
    payloads: map[string, string]
    error: string
end

func is_valid_hex(value: string) -> bool
    if length(value) % 2 != 0 then return false end
    let index: int = 0
    while index < length(value) do
        let character: string = strings.char_at(value, index)
        if !strings.contains("0123456789abcdefABCDEF", character) then return false end
        index = index + 1
    end
    return true
end

func decode_hex(value: string) -> string
    return to_str(hex_decode(value))
end

func read_size_matches(content: string, expected_size: int) -> bool
    return length(to_bytes(content)) == expected_size
end

func replay(path: string) -> ReplayResult
    let payloads: map[string, string]
    let file_info: io.FileInfo = io.stat(path)
    if !file_info.exists || file_info.is_dir then
        return ReplayResult(false, payloads, "failed to read database log")
    end
    let file: io.File = io.open(path, "r")
    if !file.open then
        return ReplayResult(false, payloads, "failed to read database log")
    end
    let read_result: io.IOResult = io.read(file)
    let close_result: io.IOCloseResult = io.close_result(file)
    if !read_result.ok || !close_result.success || !read_size_matches(read_result.data, file_info.size) then
        return ReplayResult(false, payloads, "failed to read database log")
    end
    let content: string = read_result.data
    if content == "" then return ReplayResult(true, payloads, "") end
    if !strings.ends_with(content, "\n") then
        return ReplayResult(false, payloads, "truncated database log")
    end
    let lines: strings.SplitResult = strings.split(content, "\n")
    let index: int = 0
    while index < lines.count - 1 do
        let fields: strings.SplitResult = strings.split(lines.parts[index], "\t")
        if fields.count == 3 && fields.parts[0] == "P" then
            if !is_valid_hex(fields.parts[1]) || !is_valid_hex(fields.parts[2]) then
                return ReplayResult(false, payloads, "invalid database log record")
            end
            let key: string = decode_hex(fields.parts[1])
            let payload: string = decode_hex(fields.parts[2])
            payloads[key] = payload
        elif fields.count == 2 && fields.parts[0] == "D" then
            if !is_valid_hex(fields.parts[1]) then
                return ReplayResult(false, payloads, "invalid database log record")
            end
            let key: string = decode_hex(fields.parts[1])
            if has_key(payloads, key) then delete(payloads, key) end
        else
            return ReplayResult(false, payloads, "invalid database log record")
        end
        index = index + 1
    end
    return ReplayResult(true, payloads, "")
end

func append_put(file: io.File, key: string, payload: string) -> io.IOWriteResult
    let record: string = "P\t" + hex_encode(key) + "\t" + hex_encode(payload) + "\n"
    return io.write_result(file, record)
end
~~~

~~~noxy
use io
use noxydb.document as document
use noxydb.storage as storage

struct LookupResult
    found: bool
    value: map[string, any]
end

struct PutResult
    success: bool
    error: string
end

struct DatabaseState
    payloads: map[string, string]
    file_fd: int
    path: string
    open: bool
    error: string
end

struct Database
    state: DatabaseState
end

func failed_database(path: string, error: string) -> Database
    let payloads: map[string, string]
    return Database(DatabaseState(payloads, 0, path, false, error))
end

func open_database(path: string) -> Database
    let payloads: map[string, string]
    if io.exists(path) then
        let replay_result: storage.ReplayResult = storage.replay(path)
        if !replay_result.success then
            return failed_database(path, replay_result.error)
        end
        payloads = replay_result.payloads
    end
    let file: io.File = io.open(path, "a")
    if !file.open then
        return failed_database(path, "failed to open database log for append")
    end
    return Database(DatabaseState(payloads, file.fd, path, true, ""))
end

func database_file(db: Database) -> io.File
    return io.File(db.state.file_fd, db.state.path, "a", db.state.open)
end

func fail_database(db: Database, error: string) -> void
    io.close_result(database_file(db))
    db.state.open = false
    db.state.error = error
end

func put(db: Database, key: string, value: map[string, any]) -> PutResult
    if !db.state.open then
        return PutResult(false, "database is not open")
    end
    let serialized: document.SerializeResult = document.serialize(value)
    if !serialized.success then
        return PutResult(false, serialized.error)
    end
    let result: io.IOWriteResult = storage.append_put(database_file(db), key, serialized.payload)
    if !result.success then
        fail_database(db, "failed to write database log")
        return PutResult(false, "failed to write database log")
    end
    db.state.payloads[key] = serialized.payload
    return PutResult(true, "")
end

func get(db: Database, key: string) -> LookupResult
    let empty: map[string, any]
    if !db.state.open || !has_key(db.state.payloads, key) then
        return LookupResult(false, empty)
    end
    let decoded: document.DeserializeResult = document.deserialize(db.state.payloads[key])
    if !decoded.success then
        fail_database(db, decoded.error)
        return LookupResult(false, empty)
    end
    return LookupResult(true, decoded.value)
end

func remove(db: Database, key: string) -> void
    if !db.state.open || !has_key(db.state.payloads, key) then
        return
    end
    let result: io.IOWriteResult = storage.append_remove(database_file(db), key)
    if !result.success then
        fail_database(db, "failed to write database log")
        return
    end
    delete(db.state.payloads, key)
end

func exists(db: Database, key: string) -> bool
    return db.state.open && has_key(db.state.payloads, key)
end

func close_database(db: Database) -> void
    if !db.state.open then
        return
    end
    let result: io.IOCloseResult = io.close_result(database_file(db))
    db.state.open = false
    if !result.success then
        db.state.error = "failed to close database log"
    end
end

func is_open(db: Database) -> bool
    return db.state.open
end

func database_error(db: Database) -> string
    return db.state.error
end
~~~

After the usage example, include these exact contract sections:

~~~markdown
## API

NoxyDB v0.2 maps string keys to JSON objects represented as
map[string, any]. Scalars, arrays, and null are valid inside a document but not
at its root.

LookupResult contains found: bool and value: map[string, any]. PutResult
contains success: bool and error: string. An existing empty object returns
found == true; an absent key returns found == false.

put() replaces the complete document. It returns document is not
JSON-compatible for invalid caller values without failing the database. An I/O
append failure returns failed to write database log and transitions the
database to failed.

## JSON domain

Documents may contain null, bool, signed 64-bit int, finite 64-bit float,
string, arrays, and recursively string-keyed maps. Bytes, structs, references,
callables, channels, wait groups, non-string map keys, NaN, infinities, and
cycles are rejected.

## State and isolation

The authoritative in-memory state is map[string, string] containing serialized
JSON. get() deserializes a fresh map on every successful lookup. Mutating the
input after put(), or mutating a returned document, cannot change database
state or persistence.

## Physical format and replay

P<TAB><key_hex><TAB><payload_hex>\n
D<TAB><key_hex>\n

storage.nx treats payloads as opaque strings. Replay strictly validates record
termination, arity, operations, hexadecimal data, and read byte count. The API
then validates every replayed payload as a JSON object before opening the file
for append.

There is no header, migration, fallback, version discriminator, or v0.1
compatibility logic.

## Lifecycle and durability

The observable states remain open, normally closed, and failed. Writes reach
the append-only log before the raw in-memory map changes. Write and close
failures are explicit. Persistence is guaranteed after close_database()
completes successfully; crash durability and fsync are not provided.

Queries, JSON Path, partial updates, indexes, schemas, collections, filters,
compaction, TTL, networking, concurrency, transactions, replication, and
sharding remain out of scope.
~~~
